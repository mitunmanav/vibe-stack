# Quick Install Commands

* **Claude Code:** `/plugin marketplace add ./vibe-stack` then `/plugin install vibe-stack@vibe-stack-catalog`
* **OpenAI Codex:** Copy or link `skills/*` into `.agents/skills/` (or add via Codex plugins)
* **VS Code / GitHub Copilot:** Copy `skills/*` into `.github/skills/`
* **Gemini CLI:** `gemini skills link ./vibe-stack/skills`
* **Universal (`npx skills`):** `npx skills add ./vibe-stack`
