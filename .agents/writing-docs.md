# Writing Human Guides in `docs/`

When you add a plain-English guide for a skill in `docs/<name>.md`, use four short sections:
1. **What it does** (one plain sentence)
2. **When to type it** (concrete everyday situations)
3. **What you will see** (the questions, browser preview, or checklist produced)
4. **How to know it worked** (observable result on screen or in `.vibe/`)
