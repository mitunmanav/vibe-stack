# Changelog

## 1.0.0

First public release.

- Nine commands for building an app in plain words: `/start-project`, `/ask-me`, `/freeze-plan`, `/build-step`, `/launch-check`, `/what-next`, `/plain-english`, `/repair`, `/undo`.
- Two beta commands: `/tidy-up` (tidies the code while every check stays green) and `/look-back` (offers guardrails after a step or repair that went badly).
- Six background skills: `clarifying`, `keeping-words`, `showing-options`, `checking-behavior`, `auditing-work`, `connecting-services`.
- A plain-words docs page for every command and background skill in `docs/`.
- Install through the Claude Code plugin catalog, or `npx skills@latest add mitunmanav/vibe-stack` for every other assistant.
