# Browser Demo Card Template (`DEMO-CARD-TEMPLATE.md`)

Write a clean, self-contained HTML page to `.vibe/previews/demo-<NN>.html` containing four scannable boxes in plain everyday words:

1. **What Is New in Step `<NN>`:** 2 plain sentences describing what you can do now.
2. **Try It Yourself in 30 Seconds (3 Clicks):**
   * `[ ]` **Click 1:** <Exact button or link to click> -> <What you should see happen>.
   * `[ ]` **Click 2:** <Exact action to try> -> <What you should see happen>.
   * `[ ]` **Click 3:** <Reload or edge case to try> -> <What you should see happen>.
3. **Automated Check Receipts (Already Verified by AI):**
   * `✅ Automated Check:` <Plain name of check> (*Failed before build as expected -> Passed after build*).
   * `🔒 Safety & Plan Audit:` 0 exposed secrets, all step requirements verified by fresh review helpers.
4. **Safety Net:** *"Want to undo this step? Type `/undo` in chat to return to Save Point `restore/<feature-slug>-<NN>`."*
