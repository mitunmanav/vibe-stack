# Wordbook Format (`WORDBOOK-FORMAT.md`)

`.vibe/WORDS.md` holds this project's everyday words. Create it when the first word is settled, and add each word the moment it settles. The first three columns stay in the user's words; only the last column may name files or code.

```markdown
# Project Wordbook

## Words We Use

| Word | What it means | Rules it always follows | Where it lives in the app (agent only) |
| :--- | :--- | :--- | :--- |
| **<Word>** | <one plain sentence: what it is> | <a rule that always holds> | `<file or data name>` |

## Words We Avoid

* **<old or confusing word>:** say **<Word>** instead.
```

When two words mean the same thing, pick the clearer one and list the other under Words We Avoid. Only words that are special to this project go in; everyday words like "button" do not.
