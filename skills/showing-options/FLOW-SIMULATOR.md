# Interactive Flow Simulator Guide (`FLOW-SIMULATOR.md`)

Build a single self-contained HTML file in `.vibe/previews/<slug>-flow.html` that lets a non-technical user click through real-world scenarios:

1. **Scenario Tabs at the Top:** Include 2 to 3 everyday story tabs (for example: *"Scenario 1: Normal Booking"*, *"Scenario 2: Canceling Last Minute"*, *"Scenario 3: Expired Invite"*).
2. **Clickable Action Buttons:** Let the user click the actual buttons a customer would click (*"Send Invite"*, *"Claim Spot"*, *"Fast-Forward 7 Days"*).
3. **Plain-English "What Just Happened" Box:** Next to the screen preview, show a simple box in everyday words explaining what changed (never raw JSON or database column names).
