# Visual Options (`VISUAL-OPTIONS.md`)

Build three options by default, at most five. Each option must disagree with the others about **structure**: a different layout, a different order of importance, or a different main action. Options that differ only in colour or wording are one option three times; if two drafts come out alike, redo one with a different layout.

1. **Switcher:** a small fixed bar at the bottom of the page, clearly not part of the design, with previous and next arrows and the current option's name ("B: Calendar first"). The left and right arrow keys also switch. The page also opens on a given option with `?option=b`, so the user can share or reload it.
2. **One line per option** under the switcher saying what the option bets on ("Puts today's bookings first; best when owners check in daily").
3. **Real content:** the project's words from `.vibe/WORDS.md` and believable sample items (real-sounding names, prices, dates). Placeholder text hides how a layout handles real lengths.
4. **Phone and computer:** each option must work at phone width as well as on a laptop.
