# When the User Is Lost (`LOST.md`)

The user has stopped following. Explain again; do not decide for them. The options, the recommendation, and the order stay exactly as they were.

| The user says | Do this |
| --- | --- |
| "I don't understand" | Say it again in shorter sentences, with one idea each, using only words from `.vibe/WORDS.md` and everyday speech. |
| "Say it another way" | Change the angle, not just the words: use a comparison from their own world, or a short story about one person using the app. |
| "Show me an example" | Walk through one concrete case with names and times, or call the Skill tool with "showing-options" for a clickable preview. |
| "What happens if I pick this?" | For each option, say what the person using the app would see, what it would cost, and whether it is easy to change later. |

Then ask the same question again. If the user picks something other than your recommendation, take it. If the confusion came from a word, settle the word and add it to `.vibe/WORDS.md`.
